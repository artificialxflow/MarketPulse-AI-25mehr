# پرامپت UAT کامل برای VS Code Copilot — پروژه drem.ir

این متن را **کپی کنید** و به Copilot بدهید (Chat یا Agent با **Simple Browser / Playwright / Browser automation**). هدف: پوشش end-to-end، اسکرین‌شات، گزارش pass/fail، و پیشنهاد بهبود.

---

## ۰. دستور کلی به Copilot

```
You are QA for the Next.js app "drem" (RTL Persian UI).

Base URL: [LOCAL: http://localhost:3000] OR [PROD: https://drem.ir]

Rules:
1. Test in order: Phase 0 → 1 → 2 → 3 (seed data before dependent flows).
2. For each step: navigate URL, perform actions, capture screenshot to tests/results/uat-v4/{step-id}-{slug}.png
3. Log: step id | URL | pass/fail | HTTP errors | short note
4. Final report: Markdown table + "Blockers" + "Improvement ideas" (product + UX + security)
5. Do not paste secrets (API keys) in the report.
6. Use cookie auth after login; credentials below.
```

## ۱. پیش‌نیاز محیط

| مورد | مقدار / اقدام |
|------|----------------|
| سرور | `npm run dev` یا Runflare بعد از deploy موفق |
| DB | `npx prisma migrate deploy` (شامل `20260421190000_v4_ai_rag_exams`) |
| OTP dev | `ENABLE_DEV_BYPASS=true`, `MASTER_OTP_CODE=0000` |
| کاربران تست (پیشنهاد) | سه شماره ۱۱ رقمی جدا در `/admin/users` با نقش‌های **admin / student / parent** |
| Bypass (اختیاری) | `BYPASS_PHONE` فقط برای یک نقش — برای UAT کامل **سه کاربر جدا** بهتر است |
| AI (اختیاری) | کلید GapGPT در env یا `/admin/settings/ai` — بدون کلید analyze متن mock برمی‌گرداند |
| پوشه اسکرین‌شات | `tests/results/uat-v4/` (ایجاد در صورت نبود) |

**API smoke (بدون UI):**

- `GET /api/health/ready` → 200
- `GET /api/ai/health` → `success`, `pgvector`, `ragChunkCount`
- `GET /api/webrtc/health` → 200

## ۷. محدودیت‌های شناخته‌شده (در گزارش «Expected gap» نگذار — «Known limitation»)

| موضوع | وضعیت |
|--------|--------|
| تخلفات زنده / proctoring حین آزمون | فاز بعد — مانیتورینگ فقط progress/heartbeat |
| انتساب **pack** به آزمون در UI | ممکن است فقط studentIds ذخیره شود |
| دکمه‌های placeholder در [`tests/CHECKLIST.md`](tests/CHECKLIST.md) | بعضی دکمه‌های داشبورد بدون عملکرد |
| admin می‌تواند `/student/*` را باز کند | by design در middleware |
| `questionCount` بدون answerKey | UI حداقل ۵ سؤال mock — answerKey را حتماً در UAT بگذارید |

## ۹. پیشنهادهای بهبود حرفه‌ای (Copilot در بخش Ideas تکرار/گسترش دهد)

1. **اسکریپت seed یک‌بار:** `scripts/seed-uat.ts` — admin/student/parent + curriculum + exam ongoing  
2. **سه `BYPASS_PHONE` در env تست** + Playwright با storage جدا (موجود در `tests/e2e/auth.setup.ts`)  
3. **فیلد answerKey در UI آزمون** با راهنما (فرمت `ABCD`)  
4. **صفحه «راهنمای UAT»** در repo لینک‌شده به همین فلو  
5. **CI:** `npm run build` + `test:e2e` روی staging قبل از `runflare deploy`  
6. **حذف/فعال‌سازی دکمه‌های placeholder** در admin dashboard  
7. **والد:** اگر فرزند لینک نشده، CTA واضح قبل از analyze  
8. **RAG:** نمایش citation منابع در analyze والد  
9. **Runflare:** اطمینان از آپلود کامل سورس (نه archive ~1KB)  
10. **امنیت:** rotate کلیدها؛ `ENABLE_DEV_BYPASS=false` در production

## ۱۰. ترتیب پیشنهادی برای یک session Copilot (~۹۰ دقیقه)

1. Phase 0: health APIs  
2. Phase 1: S1–S6 seed  
3. Phase 2: E1–E13 آزمون  
4. Phase 3: P1–P4 والد  
5. Phase 4: A1–A5 AI  
6. Phase 5: crawl همه URLهای بخش ۴ (smoke: صفحه 200، بدون crash)
