## V11-01 — ورود / دامنه

1. برو `https://deripin.com/login`
2. **انتظار:** متن «مطمئن شوید در دامنه https://deripin.com هستید»
3. اسکرین کامل کارت ورود

---

## V11-02 — چشم رمز (B4)

1. شماره موبایل تست → ادامه → مرحله «ورود با رمز»
2. **انتظار:** آیکون چشم در **سمت راست** (شروع RTL)؛ placeholder «حداقل ۱۰ کاراکتر» روی چشم نیفتد
3. کلیک چشم → نمایش/مخفی رمز
4. اسکرین قبل و بعد

---

## V11-03 — نمودار بازار (رفع D5)

1. ورود به داشبورد → **بازار معاملات** (`/dashboard/market`)
2. نمودار را با موس حرکت دهید
3. **انتظار:**
   - `role="tooltip"` یا باکس قیمت/زمان بالای نمودار
   - خطوط خط‌چین متقاطع (crosshair)
   - نقطه روی خط قیمت
4. اسکرین هنگام hover

---

## V11-04 — اوردربوک

1. همان صفحه بازار → پنل اوردربوک
2. **انتظار:** عنوان **«اوردربوک»** — بدون کلمه «والکس»

---

## V11-05 — درصد موجودی (بدون معامله)

1. `بازار معاملات` یا `معامله سریع`
2. دکمه‌های **۲۵٪ / ۵۰٪ / ۷۵٪ / ۱۰۰٪** را بزنید
3. **انتظار:** مقدار فیلد خرید/فروش عوض شود؛ کارمزد نمایش داده شود
4. **انجام ندهید:** دکمه تأیید نهایی / execute
5. اسکرین بعد از ۵۰٪

---

## V11-06 — ناوبری داشبورد

1. `/dashboard` → کلیک **موجودی تتر** → باید `/dashboard/wallet`
2. بازگشت → کلیک **فعالیت ۷ روز اخیر** → `/dashboard/history`
3. سایدبار جستجو: «کیف» → پیشنهاد کیف پول
4. ادمین: جستجو `KYC` → `/admin/kyc`
5. اسکرین جستجو

---

## V11-07 — گیت تأیید تماس (۴-۲)

**حساب A:** فقط موبایل OTP تأیید‌شده، ایمیل verify نشده.

1. ورود با حساب A
2. **انتظار:** داشبورد **باز** است (نه بنر اجبار فقط ایمیل)
3. **حساب B (اختیاری):** بدون هر دو verify → بنر «تأیید حساب» + لینک تنظیمات

اسکرین هر دو اگر ممکن است.

## V11-08 — FAQ (E.11.2.6–8)

1. ادمین → محتوای سایت → FAQ
2. یک سؤال را **حذف** → ذخیره تغییرات
3. تب جدید → صفحه اصلی → بخش FAQ (hard refresh Ctrl+F5)
4. **انتظار:** سؤال حذف‌شده **نیست**
5. اسکرین ادمین + لندینگ

---

## V11-09 — تیکت ادمین (G2)

1. ادمین → پشتیبانی → تیکتی که **پیوست تصویر** دارد (از قبل)
2. **انتظار:** لینک با نام فایل — **نه** متن خام `attachments:[{...}]`
3. کلیک لینک → تصویر باز شود
4. اسکرین

*(ایجاد تیکت جدید با پیوست اختیاری — بدون داده حساس در اسکرین)*

---

## V11-10 — مارکت‌میکینگ

1. ادمین → مارکت‌میکینگ
2. **انتظار:** توضیح «غیرفعال برای معامله»؛ سوئیچ **خاموش و غیرقابل تغییر**؛ فیلدها read-only؛ **بدون** دکمه ذخیره
3. اسکرین

---

## V11-11 — آرکپچا (فقط اگر env روی سرور ست شده)

1. `GET https://deripin.com/api/auth/captcha-status` → `enabled: true`
2. صفحه login → ویجت آرکپچا دیده شود
3. بدون حل کپچا → ارسال OTP/ورود → خطای «کپچا»
4. اگر `enabled: false` → TC را **Skipped** بنویسید (تا rotate کلید و env)
