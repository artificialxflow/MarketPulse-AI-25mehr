## وضعیت الان (مهم)

Health روناک درست است (`authConfigured: true`).  
**اتاق جدا «روناک» مثل `/wordpress` هنوز در محصول نیست.**  
روناک v13 = **داشبورد ۶ گام** + **تنظیمات انتشار → سایت کدنویسی (ingest)**.  
وردپرس = فقط **`/wordpress`**.

یوزر/پس **روناک** برای ingest لازم نیست؛ فقط **Bearer** همان `MATNVA_INGEST_SECRET` داخل پروژه متنوا. ورود به **matnva.ir** با کاربر امامی (یا ادمین) برای UI کافی است.

## روناک — **الان** دقیقاً چه کار کنید (ساده)

| مرحله | کجا |
|--------|-----|
| 1 | `matnva.ir` → لاگین کاربر روناک |
| 2 | داشبورد → پروژه با `siteUrl=https://ronakcare.ir`، ذخیره **database** |
| 3 | تنظیمات انتشار → ingest URL + **همان secret** Runflare روناک → Health → ذخیره |
| 4 | کلیدواژه → خوشه → تولید → تأیید → صف → انتشار |
| 5 | `ronakcare.ir/blog/...` |

Health را قبلاً زدید؛ مرحله ۳ در UI متنوا مانده.

## چیزی که می‌خواهید (اتاق روناک + روزی یک‌بار خودکار)

این **طرح محصول** است، هنوز یک صفحه `/ronak` نیست:

- یک منو: **«روناک‌کر»** (مثل «انتشار در وردپرس»)
- یک صفحه: نام پروژه، ingest (پیش‌پر شده)، **یک باکس کلیدواژه** (Enter → صف)
- پرامپت‌های روناک ثابت در همان پروژه
- **semi_auto + cron روزی ۱** → بدون کلیک بین گام‌ها
- بعداً: شاخه **محصول + GEO** → `kind: product` در همان ingest

**الان:** همان کار با داشبورد + cron `CRON_SECRET` و drain صف.  
**برای ساخت UI `/ronak`:** حالت **Agent** بگویید تا مثل `WordpressStudio.tsx` پیاده شود.

## یوزر/پس کجا؟

| چیز | کجا |
|-----|-----|
| ورود متنوا | `/login` — کاربر امامی (ادمین کاربر می‌سازد) |
| secret روناک | Runflare روناک + فیلد Ingest Secret پروژه (نه env متنوا) |
| ورود پنل روناک | فقط برای دیدن بلاگ در ادمین؛ ingest از متنوا با Bearer است |

اگر بخواهید Copilot فقط **روناک** را تست کند، در prompt فقط بخش **A** را نگه دارید و **B** را حذف کنید.
