# بسته ۳۳/۰۱ — چه تغییر کرد و چطور تست کنید (برای Copilot)

**مهم:** این فیکس در **کد محلی** (`pasteurmed10tir`) اعمال شده. اگر فقط `https://pasteur.plus` را بدون deploy جدید تست کنید، ممکن است هنوز رفتار **قبل از فیکس** (اسکرین‌شات‌های `01`–`05`) را ببینید. برای regression درست یکی از این دو را استفاده کنید:

- **`npm run dev`** روی همان branch که فیکس merge شده → `http://localhost:3000`
- یا **pasteur.plus** بعد از deploy همان commit

## ۲. آدرس‌ها (وب)

پایه: **`BASE_URL`** = `http://localhost:3000` یا `https://pasteur.plus`

| نقش | مسیر | هدف تست |
|-----|------|---------|
| ورود ادمین | `{BASE_URL}/admin/login` | لاگین دستی شما |
| پرونده ادمین | `{BASE_URL}/admin/health-records` | فرم ثبت برای بیمار |
| ورود بیمار | `{BASE_URL}/account` یا مسیر login سایت | لاگین دستی بیمار |
| پرونده بیمار (وب) | `{BASE_URL}/account/health-record` | فرم ثبت خود بیمار |
| پرونده بیمار — دندان | `{BASE_URL}/account/health-record?section=dental` | همان، بخش دندان |
| پرونده بیمار (اپ) | `{BASE_URL}/app/health-record` | اگر UI اپ را جدا تست می‌کنید |
| گزارش پرونده | `{BASE_URL}/account/health-record/report` | اختیاری؛ فقط مشاهده |

در ادمین، در کارت **«ثبت مورد جدید»** از dropdown **«بخش ثبت»** بخش را عوض کنید (نیازی به انتخاب بیمار برای **دیدن فرم** نیست؛ برای **ذخیره** بیمار لازم است).

## ۳. چک‌لیست Regression (فاز B)

برای هر مورد: **PASS / FAIL** + screenshot (بدون نام/موبایل بیمار در تصویر).

### A — پنل ادمین (`/admin/health-records`)

**A1 — بخش «عمومی»**

1. بخش ثبت = **عمومی**
2. **PASS** اگر:
   - برچسب **«نام ثبت‌کننده»** (نه «لیست پرسنل اورژانس»)
   - کنترل **`<select>`** (نه input متن)
   - گزینهٔ اول: «— انتخاب از لیست پرسنل و پزشکان —»
   - با باز کردن select، **چندین گزینه** (تعداد را بنویسید؛ **نام اشخاص را در گزارش چاپ نکنید**)
3. پایین فرم: **«توصیه‌ها»** هست؛ **«مراقبت‌ها»** در فرم ثبت جدید **نیست**
4. Screenshot پیشنهادی: `11-after-admin-general.png`

**A2 — بخش «دندان»**

- همان A1 برای ثبت‌کننده
- Screenshot: `12-after-admin-dental.png`

**A3 — بخش «حیاتی / قند / نوار» (vitals)** *(در Baseline `01` فقط text بود)*

- برچسب **«نام ثبت‌کننده»** + **select** (نه textbox)
- Screenshot اختیاری: `11b-after-admin-vitals.png`

**A4 — یک بخش تخصصی (مثلاً ارتوپدی)**

- برچسب **«نام پزشک»** + **select** (همان لیست)
- بدون «مراقبت‌ها» در فرم جدید

**A5 — API (اختیاری، DevTools Network)**

- بعد از باز شدن صفحه ادمین پرونده: درخواست موفق به  
  `/api/admin/operations/health-records/registrar-options`  
  با `{ items: [...] }`

---

### B — حساب بیمار

**قبل از تست:** از ادمین **خروج** یا **Incognito/تب جدید**.

**B1 — عمومی** — `{BASE_URL}/account/health-record`

- **PASS** اگر در «ثبت جدید» **هیچ** مورد زیر نباشد:
  - «نام ثبت‌کننده»
  - «لیست پرسنل اورژانس»
  - «نام پزشک»
  - select با placeholder «انتخاب از لیست پرسنل و پزشکان»
- **«مراقبت‌ها»** در فرم ثبت جدید **نیست**
- Screenshot: `13-after-patient-general.png`

**B2 — دندان** — `{BASE_URL}/account/health-record?section=dental`

- همان B1
- Screenshot: `14-after-patient-dental.png`

**B3 — نسخه (prescription)** — `?section=prescription`

- فیلد «نام پزشک» در فرم بیمار **نباید** باشد (همان filter روی `doctorName`)

---

### C — سوابق قدیمی (فقط مشاهده)

- اگر بیماری **سابقهٔ قدیمی** با `care` یا `doctorName` دارد:
  - در لیست **«سوابق این بخش»** (نه فرم ثبت جدید):
    - خط **«پزشک: …»** برای `doctorName`
    - در جزئیات، در صورت وجود دادهٔ قدیمی، **«مراقبت‌ها»** ممکن است دیده شود
- **ذخیره/ویرایش نکنید** مگر برای تست جداگانه
- Screenshot: `15-after-history-compatibility.png`

## ۶. اگر هنوز FAIL می‌بینید

1. **Branch/commit:** آیا همان کدی که فیکس دارد اجرا می‌شود؟
2. **Production:** pasteur.plus بدون deploy → رفتار قدیمی طبیعی است.
3. **لیست خالی در ادمین:** اگر API خطا دهد یا `items` خالی باشد، dropdown دوباره به **input متن** برمی‌گردد (`registrarOptions.length === 0`). Network tab را چک کنید.
4. **Cache:** hard refresh یا incognito.

## ۷. Agent mode

اگر بخواهید Copilot/Cursor **خودش** در مرورگر تست کند یا deploy/commit انجام شود، **Agent mode** را فعال کنید. در **Ask mode** فقط راهنما و تأیید وضعیت کد ممکن است (فیکس در repo شما از قبل اعمال شده).

اگر خواستید، می‌توانم یک **جدول نتایج خالی** برای paste کردن خروجی Copilot در `health-record-browser-uat.md` (فقط متن، بدون ویرایش فایل در Ask mode) هم بفرستم.
