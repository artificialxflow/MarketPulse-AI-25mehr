نام پروژه: MarketPulse-AI
هدف: ساخت یک اسکریپت کاملاً خودکار، مجزا و Standalone با پایتون جهت وب اسکریپینگ، استخراج نظرات/داده‌ها، تحلیل احساسات با هوش مصنوعی و تولید گزارش ساختاریافته برای بازخورد به تیم توسعه.

لطفاً تمام فایل‌ها و ساختار کدی این پروژه را به صورت کاملاً اجرایی (Production-Ready) در همین مسیر ایجاد کن:

۱. ساختار فایل‌های پروژه:
   - main.py (نقطه ورود و اجرای اصلی جریان کاری)
   - scraper.py (استخراج داده‌ها با Playwright و هندل کردن اسکرول/لودینگ)
   - analyzer.py (ارسال داده‌ها به API هوش مصنوعی برای کلاس‌بندی و تحلیل احساسات)
   - config.py (مدیریت کلیدهای API، تنظیمات پراکسی و مسیرها)
   - requirements.txt (کتابخانه‌های مورد نیاز: playwright, openai, pydantic, python-dotenv)
   - .env.example (نمونه تنظیمات متغیرهای محیطی)
   - /output (پوشه ذخیره‌سازی گزارش‌های نهایی)

۲. جزئیات پیاده‌سازی فنی:
   - بخش Scraper (در فایل scraper.py):
     * استفاده از Playwright به صورت Headless جهت لود کامل صفحات جاوااسکریپتی.
     * امکان خواندن درخواست‌های شبکه (Network Interception) برای پیدا کردن APIهای پنهان (JSON) در صورت وجود.
     * پشتیبانی از اسکرول خودکار و کلیک روی صفحه بعدی (Pagination).
     * قابلیت تنظیم Proxy (جهت جلوگیری از بلاک شدن IP).
   
   - بخش Analyzer (در فایل analyzer.py):
     * دریافت متن‌های استخراج‌شده و گروه‌بندی دسته‌ای (Batch Processing).
     * استفاده از OpenAI / Groq API با قابلیت Structured Output (با استفاده از Pydantic).
     * خروجی منطبق بر فیلدهای: sentiment (مثبت/منفی/خنثی/اسپم)، category (باگ، پیشنهاد UX، قیمت‌گذاری، کیفیت)، summary (خلاصه نظر)، priority (اولویت بالا/متوسط/پایین).

   - بخش Report Generator (در فایل main.py):
     * خروجی نهایی را در دو فرمت ذخیره کن:
       ۱. `output/market_report.csv` برای تحلیل در اکسل.
       ۲. `output/cursor_action_plan.md` (یک فایل Markdown با فرمت کاملاً دقیق و پرامپت‌گونه که شامل لیست باگ‌های کشف‌شده و پیشنهادات بهبود باشد تا بتوانم مستقیم آن را به پروژه اصلی‌ام ببرم).

۳. کدهای آماده و راهنمای اجرا:
   - فایل requirements.txt را کامل بنویس.
   - راهنمای متنی کوتاه در انتهای کار بده که چطور پایتون و Playwright را نصب و `main.py` را اجرا کنم.
